# About this site

This project is a polished fork of the Content Wind theme. The focus is on clarity, reuse, and production readiness rather than a demo-only setup.

## What changed

- Refined typography, spacing, and button states for better readability and accessibility
- Cleaned up content to highlight the value of the starter instead of the template internals
- Added mobile-first layout guidance and more purposeful calls to action

## Tech stack

- Nuxt 3 with document-driven routing from Nuxt Content
- TailwindCSS for utility-first styling with dark/light support
- Iconify for flexible icon usage

## Working practices

- Content lives in `content/` with front-matter for navigation, SEO, and open graph data
- UI building blocks sit in `components/content/` and stay presentation-only
- Configuration is centralized in `app.config.ts` and `nuxt.config.ts` for easy tweaking

## Editing checklist

- Keep headlines short (40–60 characters) and copy scannable
- Use `::button-link` for primary actions; reserve ghost variant for secondary actions
- Include descriptive `head` metadata on every page for SEO/social sharing
- Test dark mode, keyboard focus, and mobile layouts before shipping
