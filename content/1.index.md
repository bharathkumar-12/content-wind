## What you get

- Document-driven content with automatic navigation
- Dark/light mode that respects the user’s preference
- Accessible, focusable controls and larger tap targets
- Reusable components for buttons and markdown callouts
- Static generation or server rendering depending on your deploy target

## Experience principles

- Clarity over cleverness: short headlines, scannable sections, generous whitespace
- Purposeful emphasis: single primary action, secondary ghost action, minimal chrome
- Keyboard friendly: visible focus rings, scrollable code samples, predictable tab order
- Mobile first: stacked layout, comfortable padding, readable line length

## Quick start

Open a terminal and run:

```bash
npm install
npm run dev
```

Then open http://localhost:3000. Edit any Markdown file in `content/` to see live updates.

## Compose with Markdown + Vue

Use Content Wind’s MDC to mix Markdown with Vue components. Example:

::markdown-block

```md
---
title: 'Welcome'
---

# Hello

Some intro copy.

## ::button-link

href: /about
icon: ph:arrow-right

::
```

::

## Ready for production

- `npm run generate` for static hosting
- `npm run build` and `npm run preview` for a server-style deploy
- Add your socials in `app.config.ts` to surface links in the navbar
